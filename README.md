# Memory-Card-Game  🃏

A simple memory card game built with HTML, CSS, and JavaScript.
---
>Features

Flip cards and find matching pairs.

Randomly shuffle cards.

Track mistakes.
---
>How to Play

1. Click on a card to reveal it.


2. Find two matching cards.


3. Match all pairs to win!
